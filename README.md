\# 输电线路螺栓销钉缺陷检测



基于 YOLOv8 的目标检测系统，用于识别输电线路连接螺栓的销钉缺失缺陷。



\## 项目结构



\- data/ - 数据集相关

\- models/ - 模型配置与权重

\- utils/ - 工具函数

\- scripts/ - 运行脚本

\- docs/ - 项目文档

\- tests/ - 测试代码



\## 环境要求



\- Python >= 3.9

\- PyTorch >= 2.0.0

\- CUDA >= 11.8（用于GPU训练）



\## 安装依赖



pip install -r requirements.txt
